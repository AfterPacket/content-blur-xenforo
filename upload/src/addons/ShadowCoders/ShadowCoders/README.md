# Content BlurPro

Content BlurPro is a conversion-focused utility that applies a sophisticated blur effect to post content for guest visitors. By teasing content instead of hiding it completely, it increases registration rates while remaining SEO-friendly. Includes customizable blur intensity and an overlay call-to-action to encourage user sign-ups

## Installation

1. Upload the add-on files to `src/addons/ShadowCoders/ShadowCoders/`
2. Install the add-on via Admin CP → Add-ons
3. Enter your license key in Admin CP → Options → ShadowCoders (if applicable)
4. Configure settings as needed
